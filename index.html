Cara pembayaran nyata: pembeli transfer ke rekening / e-wallet / QRIS milik pemilik situs (diatur lewat panel Pengaturan, lalu dibungkus ke file HTML dan di-upload ke GitHub). Bukti transfer dikirim via WhatsApp; pemilik memverifikasi dan mengirim kode konfirmasi yang dimasukkan pembeli untuk melunasi pesanan. Tidak ada gateway pihak ketiga — dana berpindah langsung antar rekening. Konfigurasi DNS untuk GitHub Pages di bagian Terbit tetap valid sungguhan.
